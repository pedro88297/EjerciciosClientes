# 02 · Ficha de un servidor de Minecraft

**Tema 2: DOM · 20–25 minutos**

Una comunidad necesita publicar la información de su servidor de Minecraft. Completa la ficha con los datos de este caso práctico, trabajando únicamente en `js/script.js`.

1. Cambia el título principal a `Minecraft · Servidor de la comunidad` y el estado a `Inscripciones abiertas`.
2. Dentro del espacio `ficha`, crea un bloque con el subtítulo `Datos del servidor` y tres párrafos: `Modalidad: supervivencia`, `Dificultad: normal` y `Capacidad: 20 personas`, en ese orden.
3. En ese mismo espacio, después del bloque anterior, crea otro con el subtítulo `Horario` y el párrafo `Viernes, de 18:00 a 21:00`.
4. Asigna la clase CSS `destacado`, ya preparada, a los dos subtítulos para que aparezcan en verde.
5. Cambia el aviso final a `Solicita acceso a la persona administradora antes de conectarte.`

Cada bloque debe ser un contenedor propio, con su subtítulo y sus párrafos dentro. Todo debe generarse al cargar la página, conservando el HTML y el CSS iniciales.

**Comprueba:** la ficha muestra los dos bloques en orden, solo sus subtítulos aparecen en verde y no queda ningún texto provisional. Revisa también en el inspector que cada bloque contiene sus propios elementos.
