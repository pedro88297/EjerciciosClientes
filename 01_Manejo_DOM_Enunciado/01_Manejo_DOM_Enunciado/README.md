# 01 · Prepara tu inventario

**Tema 2: DOM · 10–15 minutos**

Prepara el inventario de un jugador usando JavaScript.

Abre `index.html` y completa `js/script.js`:

1. Selecciona `#titulo` con `getElementById()` y cambia su `textContent` a `Inventario de Link`.
2. Crea un `li` con `createElement()`. Ponle el texto `Espada de madera` y asigna `objeto` a su `className` para que se vea verde.
3. Selecciona `#inventario` y añade el nuevo elemento con `appendChild()`.

**Comprueba:** al recargar la página debe aparecer el título `Inventario de Link` y, debajo, una lista con `Espada de madera` en verde.
